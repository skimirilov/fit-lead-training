# Размещение Fit&Lead

Используется GitHub Pages + Google Apps Script + закрытая Google Таблица.
Полная инструкция: [GOOGLE_SETUP.md](GOOGLE_SETUP.md).

Render и Neon для этой схемы не требуются; платные ресурсы не создавались.
Реальный URL Apps Script задаётся в web/settings.js после подтверждения Google. Затем scripts/prepare_pages.py подготавливает docs для GitHub Pages. До настройки API скрипт публикации намеренно останавливается.
