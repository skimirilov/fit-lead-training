# Fit&Lead — инструкция для HR

Обучение кандидатов: https://skimirilov.github.io/fit-lead-training/

Панель HR: https://skimirilov.github.io/fit-lead-training/hr/

База Google: [адрес закрытой базы выдан владельцу отдельно]

## Вход
Пароль HR выдан отдельно в локальном файле `data/Доступы.md`. Для входа нужен только пароль, логина нет. Кандидатам пароль не передавайте. Доступ к самой Google Таблице — через ваш Google-аккаунт; она не опубликована для всех.

## Как выдать обучение
Отправьте кандидату только ссылку на обучение. Он вводит ФИО, читает предупреждение и подтверждает старт. С этого момента отсчитываются 72 часа на три блока. Каждое видео кандидат подтверждает кнопкой «Я посмотрел(а) видео».

Прогресс сохраняется в Google Таблице. Закрытие страницы не останавливает срок. При просрочке обучение можно закончить, HR увидит соответствующий статус. Для другого устройства кандидат сохраняет код восстановления и вводит его на стартовой странице.

После третьего блока кандидат видит результат, необязательный отзыв и предложение написать @daricda в Telegram.

## Как посмотреть результаты
Откройте HR-панель и введите пароль. Используйте поиск по ФИО, фильтры статуса и периода начала, сортировку по дате, прогрессу и дедлайну. Нажатие на имя открывает даты, длительность и отзыв. Кнопка CSV выгружает результаты. Даты панели показаны по Москве.

Сессия HR действует до 6 часов; Google может завершить её раньше — войдите снова. После работы нажимайте «Выйти».

## Работа с таблицей
Не переименовывайте вкладку «Кандидаты» и не переставляйте столбцы: к ним обращается сервер. Для своих отчётов используйте отдельный лист или CSV. Таблица содержит служебные хеши доступа; их нельзя редактировать. Храните таблицу закрытой, доступ выдавайте только конкретным доверенным сотрудникам.

Резервная копия: «Файл» → «Создать копию», с проверкой прав доступа к копии. CSV не заменяет полной копии базы.

## Если сайт не отвечает
Дождитесь ответа Google. При сообщении об ошибке повторите подключение или действие. Сайт показывает успех только после ответа сервера; повторное подтверждение блока не создаёт дубликат. Google Apps Script имеет ограничения по квотам и времени выполнения.
